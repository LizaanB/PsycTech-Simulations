# PSYC Tech Simulators Website

A comprehensive full-stack website for PSYC Tech Simulators featuring lead generation, product showcase, interactive 3D container viewer, quote system, booking system, and client dashboard.

## Project Overview

This website showcases mobile simulator containers (Racing Simulator and Target Shooting containers) with:
- Interactive 3D container viewer
- Quote request system
- Booking & rental management
- Client dashboard for tracking orders
- Admin portal for managing leads and projects
- Gallery with filtering capabilities
- SEO optimization for South Africa market

## Technology Stack

- **Frontend**: Next.js 14+, React, TypeScript, Tailwind CSS
- **Backend**: Node.js, Express
- **Database**: PostgreSQL
- **3D Visualization**: Three.js
- **Authentication**: JWT-based auth system

## Features

1. Home Page - Hero section with CTAs
2. Simulator Containers - Product pages (Racing & Target Shooting)
3. 3D Container Viewer - Interactive viewer
4. Gallery - Filterable media gallery
5. Specifications - Technical details & downloadable PDFs
6. Industries Served - Use cases showcase
7. Quote System - Customizable quote requests
8. Booking System - Rental booking
9. Client Dashboard - Order tracking and management
10. Admin Portal - Lead and project management
11. About Us - Company information
12. Contact Page - Contact forms and info
13. SEO Features - Optimized for target keywords
14. Future Features - Configurator, VR, Event Calendar

## Getting Started

```bash
# Clone the repository
git clone https://github.com/LizaanB/PsycTech-Simulations.git

# Install dependencies
npm install

# Run development server
npm run dev

# Open http://localhost:3000
```
